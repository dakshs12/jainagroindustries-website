# Jain Agro Industries Website - Project Requirements

## System Requirements
- PHP: >= 8.2
- Node.js: >= 20.0 (Recommended for Vite/Tailwind 4)
- Composer
- NPM (or Yarn/PNPM)
- Database: SQLite, MySQL, PostgreSQL, or SQL Server (configured via .env)

## PHP / Composer Dependencies (Backend)
- laravel/framework: ^12.0
- filament/filament: ^5.2
- laravel/tinker: ^2.10.1
